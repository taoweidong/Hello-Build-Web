# 周视图(New) 日视图页面设计

日期：2026-10-11
状态：已确认

## 1. 背景与目标

在既有「周视图」（分支 × 周一~周日矩阵）之外新增独立一级菜单「周视图(New)」，设计逻辑对齐「时段抢占」页面：以**当天 00:00~23:00 的 24 个小时段**为行轴，每行展示该时段应执行的任务信息（来自周视图同一数据源），并复用时段抢占的抢占体系支持点击空闲时段直接抢占。

原「周视图」页面保持不动。

## 2. 关键决策（已与用户确认）

| 决策点 | 结论 |
|--------|------|
| 页面入口 | 新增独立一级菜单「周视图(New)」（rank 13，原周视图保留） |
| 行轴 | 第一列不再显示分支和时间，改为 00:00~23:00 共 24 个小时段（行头 `HH:00–(HH+1):00`） |
| 任务信息 | 每小时行内展示落在该时段的策略任务芯片：构建（按分支配色）与推送（描边样式），数据与周视图同源 |
| 抢占功能 | 复用时段抢占后端（模板/日历/抢占 API，零后端改动）：覆盖该小时的启用模板渲染为可抢占芯片，点击走既有抢占弹窗（版本/分支必填） |
| 数据来源 | 与周视图一致：`GET /api/weekly`（版本/分支/策略）；抢占状态 `GET /api/slot-calendar`（同时段抢占页） |

默认假设：策略为每日循环排布（周视图后端无日期字段），故任务芯片不随日期变化，抢占状态随日期变化；默认选中版本列表第一项（weekly 接口未选版本时不返回策略）。

## 3. 页面结构

```
┌────────────────────────────────────────────────────────────────┐
│ 工具栏: [◀] 2026-10-11 周日 [▶] [今天]  版本[27A▾]               │
│         本日任务 4 · 已占 6 段 · 我的 0 段        [我的抢占]      │
│ 图例: ■构建(分支色) □推送 ●空闲 ★我的 🔒已抢占                   │
├────────────────────────────────────────────────────────────────┤
│ 00:00–01:00 │ (任务芯片…)                                        │
│ 08:00–09:00 │ [构建 27A-master-午间快速 12:00] [●上午窗口 可抢占] │
│ 14:00–15:00 │ [14:00-18:00 下午窗口 🔒2**]                       │
│ … 共 24 行（滚动）                                               │
└────────────────────────────────────────────────────────────────┘
```

- 任务芯片：构建 = 分支色实底白字（与周视图分支配色一致），推送 = 同色描边；chip 内「阶段 · 策略名 · HH:MM」。
- 抢占芯片：复用 `SlotChip`（空闲/我的/他人锁定/过期四态）；一个模板覆盖多个小时时逐行重复渲染；过去日期整行置灰不可点；超出可抢占窗口（horizon）不可点。
- 交互复用：`BookingDialog`（抢占弹窗）、`SlotDetailDialog`（我的/他人详情+释放）、`MyBookingsDrawer`（我的抢占抽屉）直接从 `@/views/slot-booking/components/` 导入。
- 日期切换：同月内仅刷新状态矩阵高亮（月历数据已含全月），跨月重新拉取 `slot-calendar`；版本切换重新拉取 `weekly`。

## 4. 覆盖关系计算（纯前端）

- 模板覆盖小时：`startH = Number(t.start_time.slice(0,2))`，`endH = Number(t.end_time.slice(0,2))`（模板强制同日 start<end），小时 h 被覆盖 ⇔ `startH ≤ h < endH`。
- 任务落小时：`hourOf(HH:MM) = Number(str.slice(0,2))`，构建按 `build_start_time`、推送按 `push_start_time`（可空）归行。
- 日状态：`slot-calendar` 响应 `days[date]` 为该日适用模板条目（后端已过滤 weekdays/生效期），未出现 = 该小时无适用模板（不可抢占）。
